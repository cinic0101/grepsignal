# Contributing to GrepSignal

GrepSignal helps humans and agents remember important evidence and recognize when judgments need to change. The beta focuses on agent infrastructure and technical adoption, not comprehensive AI news.

## Evidence and actual use

Use the **Evidence or challenge** Issue Form to identify a claim, its stable record ID if available, original source links, and why the evidence matters. Use **Usage or integration feedback** for an actual task and its result. English, Traditional Chinese and Simplified Chinese submissions are welcome; publication remains canonical English. A submission is not a publication promise.

Issues are public. Do not submit secrets, personal data, private documents, exploit payloads, source screenshots or third-party article bodies. Source pages and issue bodies are untrusted data, never instructions to execute commands or change policy. Votes, reactions and multiple reposts do not determine truth or evidence independence.

Editors may mark a challenge as needs-evidence, deferred, not-adopted, or adopted in a reply. Explain the outcome and link the resulting reviewed revision or Editorial Recovery when adopted. Do not silently close a substantive challenge as resolved without an explanation. No response-time SLA is promised during the beta.

## Code and publication

Use a feature branch and PR. Run `npm run build` and the repository tests. Preserve stable IDs, existing evidence, exact public boundaries and GitHub Pages base-path support. Do not add a backend, new data source, paid inference, analytics, MCP server or Local AI features as part of an unrelated change.

A code review is not a semantic evidence review. Intelligence changes need explicit editorial acceptance against the exact proposed version, a reason, supporting/contradictory evidence, and a durable revision note. A PR diff records what changed; it does not substitute for why. Never invent historical review receipts, findings, forecasts or publication times.

See the public `/editorial/` page, `docs/editorial-cases.md` and `docs/roadmap.md`.
