# Editorial writing guidance

This is a writing-quality aid, not a truth oracle or publication gate. Evidence quality, scope, limitations, and editorial acceptance remain authoritative.

## Responsibilities by field

- **Title** — name the material change plainly. No fixed grammatical pattern is required.
- **Summary** — state what changed. Prefer one or two sentences when that is enough.
- **Why it matters** — explain the builder-facing consequence; do not simply restate the summary.
- **Second-order effect** — move one step downstream from the direct consequence. If there is no defensible downstream effect, narrow the claim instead of manufacturing one.
- **Watch next** — name observations that could update the judgment, not generic advice to “monitor the space.”

## Style smells

The build runs a non-blocking editorial advisory. It currently flags:

- sentences longer than 30 words,
- repeated “material change/shift … not … but …” constructions,
- repeated “is/are becoming” title constructions,
- unusually dense Signal summaries.

These are review prompts, not failures. A long sentence may be the clearest sentence. A repeated construction may be justified. The purpose is to prevent the publication layer from drifting into visibly templated LLM prose.

## What the program must not do

The advisory must not:

- rewrite published intelligence,
- lower or raise a Signal gate,
- manufacture a different title merely to satisfy style variety,
- change a factual scope, limitation, falsifier, or status,
- block publication on a style heuristic alone.

Material wording changes to an already published judgment belong in the accountability flow; they are not cosmetic UI edits.
