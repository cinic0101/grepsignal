# Integrated roadmap — A / B / C first

Product: help humans and agents know what is worth remembering and which judgments need to change. Initial scope: agent infrastructure and technical adoption.

## A — Public contract and feedback

Clear scope, human/model/program responsibilities, evidence and correction policy, CC BY 4.0 for authorized original intelligence, Apache-2.0 software, Evidence/Challenge and Usage/Integration Issue Forms. Crowd feedback is a discovery/validation input, never a vote on truth. Exposure, actual use and independent deployment are distinct observations.

## B — Minimal durable history

Stable identity, source lineage, honest timestamps, original judgments, version-bound acceptance, explicit correction reasons, narrow relations. Keep judgment assessment separate from record lifecycle. Preserve unknown legacy dates and reviewer scope instead of fabricating history. Do not rebuild the intake ledger or invent a general knowledge-graph platform.

## C — Accountability loop and change delivery

Due-review context in the existing workflow; explicit reviewed/unchanged/inconclusive outcomes; bounded counter-evidence work; immutable prediction criteria with human resolution and deterministic scoring; visible corrections/retractions; one canonical history producing JSON and a sitewide Atom feed. Fixtures exercise failures without creating fake public intelligence. New material changes require editorial acceptance; deterministic coverage refresh remains separate.

## Deferred until A/B/C are reviewed

Discuss and select the first China-native ecosystem evidence layer. Do not add Chinese discovery sources, rename brands, open the private engine, add MCP/dynamic APIs, expand Local AI, add analytics, change live schedules, or manufacture forecasts in A/B/C. Independent OSS deployment is a later work package, not implied by an open static website.

Success is repeatable useful judgment maintenance, not daily output, weakening counts, source quotas or stars. Actual adoption and forecast calibration remain unproven until observed.
